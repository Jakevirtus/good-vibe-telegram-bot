# GoodVibeBot 🤖✨

![tests](https://img.shields.io/badge/tests-5%20passed-brightgreen)
![coverage](https://img.shields.io/badge/coverage-65%25-yellow)

**GoodVibeBot** — проект, который развивается от простого бота-комплимента до личного помощника. Он будет поднимать настроение, подсказывать погоду и рассказывать, какие сегодня праздники отмечают в разных странах.

**Сейчас (Уровень 1):** бот дарит комплименты и поднимает настроение.
**В планах (Уровни 2–3):** погода, праздники, база данных и деплой на сервер.

Подробное описание всех уровней — в разделе [«Статус проекта и планы»](#-статус-проекта-и-планы).

## 🛠️ Стек технологий

- **Язык:** Python 3.13
- **Библиотека для бота:** [aiogram](https://github.com/aiogram/aiogram)
- **Управление переменными окружения:** [python-dotenv](https://github.com/theskumar/python-dotenv)
- **Поддержка прокси:** [aiohttp-socks](https://github.com/romis2012/aiohttp-socks)

## 🚀 Как запустить локально

Для запуска бота на вашем компьютере потребуется Python 3.10+ и установленный Git.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Jakevirtus/good-vibe-telegram-bot.git
   cd good-vibe-telegram-bot
   
2. **Создайте и активируйте виртуальное окружение:**
   ```bash
   python -m venv .venv
   # Для Windows:
   .venv\Scripts\activate
   # Для macOS/Linux:
   source .venv/bin/activate
   
3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   
4. **Настройте переменные окружения:**
   Создайте файл `.env` в корне проекта (рядом с `bot.py`) и добавьте туда ваш токен:
   ```ini
   BOT_TOKEN=ваш_токен_от_BotFather
   # Если вы находитесь в регионе с блокировками Telegram API, 
   # раскомментируйте строку ниже и укажите адрес вашего прокси:
   # PROXY_URL=socks5://127.0.0.1:1443
   
5. **Запустите бота:**
   ```bash
   python bot.py
   Чтобы остановить бота, нажмите Ctrl + C в терминале.
   
## 📌 Статус проекта и планы

- **Текущий статус:** Уровень 1 (Базовый). Бот работает, отвечает на команды и дарит комплименты.

- **Планы на будущее:**

  - [x] **Уровень 1:** Базовый функционал (комплименты, эхо).

  - [ ] **Уровень 2:** Интеграция с внешними API (базовая версия):
    - **Погода.** Пользователь вводит город, а бот присылает текущую температуру и краткое описание.
    - **Праздники.** Пользователь вводит дату, а бот отвечает, в каких странах из заданного списка (Россия, США, Германия, Китай, Япония и др.) этот день является праздником.

  - [ ] **Уровень 3:** Упаковка в Docker и деплой на сервер (размещение бота в интернете для круглосуточной работы):
    - **Глобальный поиск праздников** по всем странам мира с кэшированием результатов в базе данных.
    - **Прогноз погоды на неделю** с фильтрацией по регионам и сохранением любимых городов пользователя.
    - Добавление базы данных (SQLite/PostgreSQL).
    - Упаковка в Docker и деплой на сервер.
